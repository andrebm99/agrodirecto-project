# P3-05 — Recuperar contraseña (MUST)

**Rama** `feat/P3-05-recuperar-contrasena` · **PR** vie 27 · **Merge** sáb 28 · **Dueño** P3
Depende de P2-02 (merge vie 27). Contrato: `contratos.md` → Recuperación de contraseña.

## Objetivo
Pantallas para pedir el correo de recuperación y fijar la nueva contraseña.

## Contexto
`Login.tsx:170-171` solo muestra un aviso. Navegación por hash (`useAgroDirecto.ts:184-215`, `AgroDirectoApp.tsx:47-63`); rutas privadas definidas en `utils/sesion.ts:42-62`. El enlace del correo es `/#restablecer?token=…`.

## Cambios
1. `services/api/auth.ts`: `olvideContrasena(email)` y `restablecer(token, nuevaContrasena)`.
2. Rutas hash públicas `#olvide` y `#restablecer` (el token se lee del hash/query y se limpia de la URL tras leerlo).
3. `#olvide`: campo correo; tras enviar siempre muestra "Si el correo existe, te enviamos un enlace" (no revela existencia).
4. `#restablecer`: nueva contraseña + confirmación (8–72 caracteres, indicador básico); éxito → mensaje y redirección a `#login`; error `TOKEN_INVALIDO` → mensaje con enlace a `#olvide`.
5. Reemplazar el aviso de `Login.tsx` por el enlace "¿Olvidaste tu contraseña?".

## Criterios de aceptación
- Flujo completo funciona contra el backend con `EnvioCorreoSimulado` (leer el enlace del log).
- Token reutilizado/expirado muestra error claro.
- Validación de campos con `erroresPorCampo`; accesible (labels, `role="alert"`).

## Tests
Unitarios de `authApi` (cuerpos y errores) y de lectura del token desde el hash.

## Fuera de alcance
Verificación de correo al registrarse.

## Verificar
`pnpm test && pnpm typecheck && pnpm lint`; manual completo.
