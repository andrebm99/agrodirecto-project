# P3-02 — Errores visibles y accesibilidad (MUST)

**Rama** `fix/P3-02-errores-a11y` · **PR** jue 26 · **Merge** vie 27 · **Dueño** P3

## Objetivo
Ninguna pantalla se queda en "Cargando…" para siempre; todo error es visible y reintentable; accesibilidad básica correcta.

## Contexto
- Errores ignorados: `src/components/Admin.tsx` (:36 Cuentas, :261 Precios, :293 Disputas, :532 Auditoría), `ProducerDashboard.tsx:228` (Productos), `useCatalogo.ts:158` (favoritos, revierte sin avisar), `Campana.tsx:353-356` (sin try/catch al marcar leídos).
- A11y: pestañas con `role="tab"` sin `aria-controls`/`tabpanel`; `Campana.tsx:347` `role="dialog"` sin foco ni Escape.
- Sin pantalla 404: `useAgroDirecto.ts:187` ignora hashes desconocidos. Un solo `<title>`.
- `useConsulta.ts:306-318` ya devuelve `error` y `regla`.

## Cambios
1. Componente `EstadoError` (mensaje + botón "Reintentar") reutilizable; usarlo en todos los lugares listados.
2. Favoritos y campana: mostrar aviso (toast/línea) al fallar y mantener el estado correcto.
3. Pestañas: `aria-controls`, `aria-selected`, `role="tabpanel"` con `aria-labelledby`, navegación con flechas izquierda/derecha.
4. `Campana`: mover foco al abrir, devolverlo al cerrar, cerrar con Escape.
5. `document.title` por pantalla ("Catálogo · AgroDirecto").
6. Pantalla 404 para hash desconocido con enlace al inicio.

## Criterios de aceptación
- Dado que la API falla en Admin → se ve el error y "Reintentar" recarga.
- Dado Escape con la campana abierta → se cierra y el foco vuelve al botón.
- `pnpm lint` (incluye `jsx-a11y`) sin avisos nuevos.
- Hash desconocido → pantalla 404.

## Tests
Unitarios de utilidades extraídas (título por ruta, lectura de ruta); `EstadoError` si se añade testing-library (ver P4-04).

## Fuera de alcance
Rediseño visual (la identidad del Avance 1 se mantiene), internacionalización.

## Verificar
`pnpm test && pnpm typecheck && pnpm lint`; manual con el backend apagado.
