# P4-01 — Limpieza de plantilla y entorno (MUST)

**Rama** `chore/P4-01-limpieza` · **PR** mié 25 · **Merge** jue 26 · **Dueño** P4

## Objetivo
Un clon limpio instala, compila y prueba sin restos de la plantilla ni archivos que fallen.

## Contexto (hallazgos)
- Sin uso: `src/integrations/chatgpt-auth.ts` (importa `next/headers`), `src/db/index.ts` y `schema.ts` (D1), `drizzle.config.ts`, `drizzle/` (solo `_journal.json`), `examples/d1/`, `next.config.ts` (vacío), dep. `nitro` (`vite.config.ts:3,53`), lectura de `.openai/hosting.json` (`vite.config.ts:6-12`), `drizzle-orm` y script `db:generate` en `package.json`.
- `.gitignore:31` ignora `.env*`, por eso no existe `.env.example` y falla `cp .env.example .env.local` del README.
- Metadatos: `package.json` se llama `agrodirecto-avance-1`; `layout.tsx:17` usa `metadataBase` `http://localhost:3000` y "Prototipo académico".
- Rótulos de demo: `Footer.tsx:25` ("Datos de demostración"), `Login.tsx:12-24` (cuentas demo visibles).

## Cambios
1. Borrar los archivos y dependencias sin uso; ajustar `vite.config.ts` (quitar nitro/hosting.json) y `tsconfig`/lint si referencian lo borrado.
2. `.gitignore`: añadir `!.env.example`; crear `.env.example` con `VITE_API_URL=http://localhost:8080` y comentario.
3. Renombrar paquete (`agrodirecto`), actualizar metadatos con la URL real y descripción final.
4. Cuentas demo: **mantenerlas** (decisión del equipo) pero mostrarlas en un bloque "Cuentas de demostración" claro y fácil de quitar con una variable (`VITE_MOSTRAR_DEMO`); ajustar `Footer.tsx:25` según corresponda.
5. Quitar el comentario obsoleto de `utils/sesion.ts:25` ("panel del agente llega en F4").
6. README: pasos correctos de instalación y variables.

## Criterios de aceptación
- En un clon limpio: `pnpm install --frozen-lockfile && pnpm build && pnpm test && pnpm typecheck && pnpm lint` pasan.
- No quedan imports a archivos borrados; el bundle no incluye `drizzle`/`nitro`.
- `cp .env.example .env.local` funciona.

Rediseño, migración de hash-routing a rutas reales.
